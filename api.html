Services

Business logic: points bookkeeping, the weighted draw of hosts and the draft life cycle.

breakfast.services.compute_points() → dict[int, float][source]

Points of every user: manual adjustments plus the outcome of every confirmed breakfast.

breakfast.services.refresh_points() → None[source]

Store the freshly computed balance on each user.

breakfast.services.draw_host(breakfast: Breakfast, rng: Random | None = None) → Host | None[source]

Add a randomly drawn host to breakfast and return it (None if nobody is left).

Only the users with the lowest balance are candidates: those at or below zero when anyone is, the single lowest otherwise. Among them, the lower the balance the likelier the draw.

breakfast.services.create_draft(date) → Breakfast[source]

Create a draft breakfast, discarding stale drafts on the way.

breakfast.services.confirm(breakfast: Breakfast) → None[source]

Mark breakfast as confirmed and update everybody’s balance.

Notifications

Serialised .ics event; with reminders it carries alerts to prepare food (for hosts).

breakfast.notifications.send_notifications(breakfast: Breakfast) → None[source]
